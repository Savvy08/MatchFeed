# MatchFeed - Android APK & Web

Автономное мобильное приложение для мониторинга live-результатов и спортивной статистики (настольный теннис, футбол) с прямой интеграцией SofaScore API.

Приложение работает полностью автономно на Android без локального PHP/Python-сервера: сетевой слой реализован на базе Chromium Cronet, обходящего ограничения CORS и TLS-проверки.

## Основной функционал

- Live-лента: события настольного тенниса и футбола с автообновлением каждые 30 секунд и звуковыми уведомлениями (Web Audio API).
- Карточка матча:
  - Обзор: интерактивное голосование, коэффициенты букмекеров (каскадный опрос featured, 1/all, 2/all с поддержкой зеркал).
  - H2H: баланс побед и поражений, детальная история личных встреч со счетом по сетам.
  - Форма: статистика побед, расчет серий (streak) и последние игры.
  - Сетка: турнирное дерево плей-офф (cuptrees) с парами участников.
  - Медиа: встроенный YouTube-плеер с хайлайтами матча и новости SofaScore.
- Профиль игрока: рейтинг, страна, физические данные, аналитика побед/поражений и история матчей.
- Избранное: быстрый доступ к отслеживаемым матчам через `localStorage`.
- Интерфейс: адаптивная верстка, полная поддержка темной и светлой тем, шторка настроек и управление кэшем.

## Архитектура и стек

- Android Shell: SmartWebView 8, Android SDK 36 (minSdk 24), Java 17.
- Сетевой стек: `com.google.android.gms:play-services-cronet` (нативные HTTP/2 и QUIC-запросы с Chrome-отпечатком).
- Frontend: чистый JavaScript (ES6+), HTML5, Vanilla CSS без внешних библиотек и фреймворков.
- Web-режим (legacy): поддержка запуска через локальный стек PHP 8.x + Python 3 (`curl_cffi`).

## Сборка Android APK

Компиляция APK автоматизирована через GitHub Actions (`.github/workflows/build-apk.yml`):
- Среда: Ubuntu 24.04, JDK 17 (Temurin).
- Команда сборки: `./gradlew assembleDebug --no-daemon`.
- Артефакт: готовый установочный `MatchFeed-debug-apk` в разделе Actions.

Для локальной сборки:
```bash
cd android
./gradlew assembleDebug
```
Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.
