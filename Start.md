### Запуск на Mac

1. **Где запускать**: в приложении «Терминал».
2. **Команда**:
```bash
cd "путь" && PHP_CLI_SERVER_WORKERS=4 php -S "[::]:8000"
```
3. **Что делает**: переходит в папку проекта и запускает сервер PHP в 4 потока на порту 8000.
4. **Что появится в результате**:
```text
PHP 8.5.10 Development Server (http://[::]:8000) started
```
5. **В браузере**: открой `http://localhost:8000`.

---

### Запуск на Windows

Перед первым запуском убедись, что на компьютере установлена библиотека:
`pip install curl_cffi`

1. **Где запускать**: в Командной строке (CMD) или PowerShell.
2. **Команда**:
```cmd
cd "C:\путь\к\MatchFeed" && php -S localhost:8000
```
*(вместо `C:\путь\к\MatchFeed` укажи папку, где лежит проект на Windows).*
3. **Что делает**: запускает локальный сервер PHP на порту 8000.
4. **Что появится в результате**:
```text
PHP 8.x Development Server (http://localhost:8000) started
```
5. **В браузере**: открой `http://localhost:8000`.

Окно терминала (на Mac) или командной строки (на Windows) во время работы приложения закрывать не нужно. Чтобы остановить сервер, нажми `Ctrl + C`.
